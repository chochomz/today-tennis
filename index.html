📖 오늘의 테니스 모임 - 이용 가이드

1. 📱 접속 및 기본 환경 설정
  • 어디서 접속하나요? 제공된 링크를 스마트폰(사파리, 크롬)이나 카카오톡 브라우저로 열면 별도 설치 없이 즉시 실행됩니다.
  • 🎨 사계절 테마 버튼: 테니스 라켓 아이콘을 클릭하여 봄, 여름, 가을, 겨울 4가지 테마 색상으로 배경을 바꿀 수 있습니다.
  • 🏷️ 경기명 입력: 상단 입력창에 오늘 모임 이름(예: 10월 정기모임)을 자유롭게 입력하면 자동 저장됩니다.
  • 📜 규칙 버튼: 코트 에티켓, 기본 규칙, 경기 규칙, 심판 규칙, 관람 규칙을 상세히 확인할 수 있습니다.
2. 📝 1단계: 선수 등록 및 대진 배정
  • 참석 인원 설정: [선수] 탭에서 참석 인원(4명~16명)을 선택합니다. (선택 즉시 최적의 KDK 대진표 자동 배정)
  • KDK 버전 선택: 기본 KDK v2010 또는 KDK v2010 (4게임) 모드를 선택할 수 있습니다.
  • ⚡ 선수 이름 입력: 1번부터 차례대로 이름을 입력합니다. 키보드의 [엔터(Enter)] 키를 누르면 다음 선수 입력 칸으로 바로 이동합니다.
3. 🎯 2단계: 경기 진행 및 점수 입력
  • 대진표 확인: [경기대진] 탭에서 각 코트별 경기 대진, 파트너, 휴식 선수를 한눈에 파악합니다.
  • 점수 입력하기: 경기 완료 후 스코어를 터치하여 입력합니다. 입력 시 완료 카드로 자동 반영됩니다.
  • ⚡ 실시간 동기화: 관리자가 수정한 점수가 모든 참가자 기기에 즉각 실시간 동기화됩니다.
4. 🏆 3단계: 실시간 순위 확인 및 공유
  • 실시간 순위표: 승수 > 득실차 > 승률 순서로 완벽하게 자동 정렬됩니다.
  • 🔍 상세 분석 팝업: 순위 원형 번호를 터치하면 선수의 파트너별 상세 전적을 조회할 수 있습니다.
  • 💬 클럽카톡방 공유: 버튼 하나로 정돈된 순위 결과 텍스트를 복사하여 카카오톡에 전송합니다.
  • 📸 캡처공유(사진): 모든 결과가 한 화면에 정리된 뷰가 열려 스크린샷으로 공유하기 편리합니다.

📜 오늘의 테니스 모임 5대 공식 규칙

1. 에티켓 (Etiquette)
  1. 코트 입장/퇴장 시 항상 밝은 미소와 목례로 인사합니다.
  2. 멋진 플레이에 아낌없는 박수와 칭찬을 보냅니다.
  3. 볼을 넘겨줄 때는 상대가 받기 편하게 정중히 전달합니다.
  4. 타인의 코트를 함부로 가로질러 통행하지 않습니다.
  5. 판정에 대해 감정을 내세우지 않고 상대 의견을 존중합니다.
2. 기본 규칙 (Basic Rules)
  1. 클럽의 정해진 시간과 운영 일정을 엄수합니다.
  2. 대진 배정 결과에 적극 순응하고 협조합니다.
  3. 코트 내에서는 반드시 테니스 전용화를 착용합니다.
  4. 부상 방지를 위해 사전 준비운동을 철저히 진행합니다.
3. 경기 규칙 (Match Rules)
  1. 정해진 복식 매칭 규정과 게임 수에 따릅니다.
  2. 서브는 대각선 방향으로 진행하며 풋폴트를 준수합니다.
  3. 라인에 걸친 공은 모두 인(In)으로 판정합니다.
  4. 노애드(No-Ad) 시스템 시 리시브 측이 코스를 선택합니다.
4. 심판 규칙 (Umpire Rules)
  1. 자기 코트의 판정은 플레이어가 직접 내립니다 (셀프 콜).
  2. 명백한 경우에만 아웃을 콜하고, 애매하면 인으로 인정합니다.
  3. 판정 시비 시 감정싸움을 멈추고 렛(재경기)을 적용합니다.
5. 관람 규칙 (Gallery Rules)
  1. 경기 중인 선수의 집중을 위해 랠리 중엔 정숙을 유지합니다.
  2. 공이 코트로 굴러가지 않도록 주변 정리를 정돈합니다.
  3. 관중석에서 선수의 셀프 판정에 관여하지 않습니다.
